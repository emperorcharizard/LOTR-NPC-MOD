# Job script: lotrnpcs 0.0.78 + haradrim-armor 0.1.0 (as built)

Written 2026-11-04. Builds on 0.0.77 (source hash `4ccd4c5bc4aed3a7`).

- **[owner]** "Use these as skins for the haradrim, mostly as a temporary placeholder", with three Blockbench files:
  `haradrim_infantry_armor(1).bbmodel`, `heavy_infantry.bbmodel`, `warlord.bbmodel` (kept unchanged in
  `build-inputs/haradrim-armor-owner-originals/`).
- **[fact]** They are armor, not skins: a "player body (not exported)" preview group plus one armor group with head,
  body and legs groups, each holding groups named after the body parts, whose origins equal the preview body's part
  corners. One embedded texture per piece (128 px at 64 UV). The warlord had two "hand_guard mirrored" cubes on the
  right forearm filed under LowerArmL.
- **[owner] chose b):** a separate armor mod players can wear too (rule from 2026-11-02 "armor is never bundled" kept).

## Built

- `tools/bbmodel_armor_to_vs.py`: splits a project into its head, body and legs pieces, keeps only each piece's
  textures, moves cubes filed under the wrong side, converts with `bbmodel_to_vs.convert`, and turns each body-part group
  into a step parented top-level element (`HR<set>_<Part>`, from 0) with texture `#material`.
- **Leg fit [my call]:** the Blockbench preview body's shin and thigh are 7 px each; the game body shows 9 px of shin and
  6 px of thigh below the torso. Pieces on LowerFoot are stretched 9/7 in Y and pieces on UpperFoot squeezed 6/7, about
  the part's bottom. Head, neck, torso and arms match the game body exactly. Checked with `tools/preview/armorpreview.py`
  on our body (`previews/haradrim-armor-0.0.78.png`).
- `tools/haradrim_armor_mod.py` builds `build-inputs/haradrim-armor-0.1.0.zip`: mod id `haradrimarmor`, nine items
  `haradrimarmor:armor-<head|body|legs>-<tierthreechain|tierfourplate|tierfiveplate>-haradrim<infantry|heavy|warlord><helmet|armor|leggings>-...-none`,
  laid out like gundabad-bone-armor. Creative inventory only, no recipes **[my call]**. Protection, durability and walk
  speed are placeholders **[my call]**: infantry 0.75 / 1.0 / tier 2 / 900, heavy 0.85 / 1.5 / tier 3 / 1300, warlord
  0.88 / 2.0 / tier 3 / 1600.
- lotrnpcs: Haradrim recruits and archers wear infantry, warriors heavy infantry, captains warlord (`HARADRIM_ARMOR`).
  New `fallbackSets` on `lotrnpcs:startinggear` (`EntityBehaviorStartingGear.CompleteSets`): the 0.0.41 Nadiyan outfits
  are worn only when no armor set is complete, so a server with the mod never mixes them. Portraits use the armor, then
  the fallback.
- Tests: factions 422 pass (5 new), spawn zones pass. Item codes cross-checked against the mod zip (9 = 9, every shape,
  texture and lang line present).
